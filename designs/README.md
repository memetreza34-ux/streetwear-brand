# Designs

Hier werden später nur **selbst entwickelte bzw. entsprechend lizenzierte** Entwürfe gespeichert.

Empfohlene Struktur für jedes ausgewählte Design:
- `konzept.md`: Idee, Zielgruppe, Farbpalette, Druckposition
- `entwurf-v01.png`: Entwurf oder Mockup
- `druckdatei.*`: separate, auf die Herstellervorgaben abgestimmte Produktionsdatei
- `freigabe.md`: Rechteprüfung, Größe, Qualität und finale Freigabe

Mockups sind kein Nachweis für Druck- oder Stoffqualität.

**Status:** Noch kein Design verabschiedet.
