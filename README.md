# Streetwear Brand – Projektzentrale

> **Projektname ist nur intern.** Es gibt noch keinen festgelegten Markennamen, kein fertiges Design und keinen aktiven Shop.

Dieses Repository bündelt die Planung einer eigenen Modemarke mit bereits vorhandenen Blanko-Kleidungsstücken (z. B. Oversized-Shirts, Hoodies und Sweatshirts). Eigene Designs werden später von einem externen Print-on-Demand-Anbieter gedruckt/bestickt; Produktion und Versand sollen möglichst ausgelagert sein.

## Prinzipien
- Einfacher Betrieb; keine eigene Produktion oder Lagerhaltung.
- Qualität und Passform vor Anzahl der Produkte.
- Erst prüfen, testen und kalkulieren; **noch keine Verkäufe**.
- Entscheidungen nachvollziehbar dokumentieren.
- Keine unnötigen kostenpflichtigen Dienste oder selbst entwickelte Shop-Software.
- Kein Design, keine Herstellerwahl und kein Markenname sind bisher verbindlich beschlossen.
